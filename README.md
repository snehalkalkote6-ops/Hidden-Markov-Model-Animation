# 🎬 Hidden Markov Model (HMM) — Solved Example

### Understanding Forward, Backward, and Viterbi Algorithms

This project explains the fundamentals of **Hidden Markov Models (HMMs)** through an educational animation and a solved numerical example.

## 🎥 Animation Video

**File:** `Hidden_Markov_Model_(SolvedExample).mp4`

The video explains HMM concepts and demonstrates the Forward, Backward, and Viterbi algorithms using a simple weather example.

## 📚 Topics Covered

- Hidden states and observations
- Initial, transition, and emission probabilities
- Forward Algorithm
- Backward Algorithm
- Viterbi Algorithm
- Comparison of the three algorithms

## 🌦️ Solved Example

The example uses a weather model with two hidden states:

- **Rainy**
- **Sunny**

The observations are **Umbrella** and **No Umbrella**, with the sequence:

`Umbrella → No Umbrella → Umbrella`

## 🎯 Learning Objective

To understand how HMMs calculate observation probabilities and identify the most likely sequence of hidden states.
